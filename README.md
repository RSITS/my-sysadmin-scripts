Это скрипт по варианту Б — Мониторинг ресурсов.

Bash-скрипт для периодического мониторинга системных ресурсов Linux.

Скрипт выполняет команды free -h, df -h и uptime именно в таком порядке.

Интервал выполнения команд 5 секунд.

Результаты с временными метками записываются в файл monitor.log, который создаётся в дирректории со скриптом.
