# Учебный проект по системному администрированию

## Описание проекта

Данный репозиторий содержит учебный проект по варианту **Б — Мониторинг ресурсов**.

Проект представляет собой bash-скрипт для периодического мониторинга системных ресурсов Linux.

## Функциональность

Скрипт выполняет следующие команды **именно в таком порядке**:

- `free -h` — состояние оперативной памяти
- `df -h` — использование дискового пространства  
- `uptime` — время работы системы и средняя загрузка

## Параметры работы

- **Интервал выполнения:** 5 секунд
- **Лог-файл:** `monitor.log` (создаётся автоматически в директории со скриптом)
- **Формат записи:** каждый блок начинается с временной метки

## Использование

### Запуск скрипта

./monitor.sh
